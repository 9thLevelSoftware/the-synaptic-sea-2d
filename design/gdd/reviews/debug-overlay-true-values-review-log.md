# Design Review Log — debug-overlay-true-values

## Review — 2026-10-27 — Verdict: NEEDS REVISION
Scope signal: L
Specialists: systems-designer, qa-lead, godot-specialist, performance-analyst, game-designer
Blocking items: 7 | Recommended: 20
Summary: Verdict: NEEDS REVISION. This is not a major revision. The pillar guard rails are sound: display only, never on the tester's screen, immune to the Filter. The structure, arithmetic and AC discipline are strong, and nothing conflicts with the user decisions in force. The trouble is concentrated in the one thing this system exists to do. The classifier separates Pillar 4 deliberate lies from defects, and as specified it raises false DEFECTs on honest play in five ways. I confirmed each in the text: (1) short-reach and unrenderable lies under row 4(a)/(b); (2) frame-counted graces, which depend on fps and keep counting while paused (lines 457-458); (3) the float equality in row 8 dropping close
Prior verdict resolved: First review
Findings:
- [BLOCKING] F-1 row 4(a)/(b) (DEFECT_SILENT_LIE), E-DO-16, E-DO-19, AC-DO-29: [main review + game-designer + qa-lead, CD confirmed] Both branches of row 4 classify lies the Filter deliberately draws with no needle departure as defects. Branch (a) fires when there is less than D_VIS_MIN_DEG of room, when room_deg <= 0, or on the Suit 5-percent boundary, where tol_eff is 12 deg and equals D_VIS_MIN_DEG. Branch (b), noted by the game-designer, fires when lie_unrenderable or E-PF-12 means the Filter creates no needle lie and lie_id stays 0. The systems-designer adds a third trigger: a moving tv sweeps through an absolute lie target and n_eq crosses its grace on a lie that was rendered correctly. AC-DO-29's 0.3 deg/s fixture lies outside the Filter's own arrival guarantee, so it never reaches the real boundary. The Overlay exists to separate Pillar 4 deliberate lies from defects. Flagging the Filter's designed fallback as a defect defeats that purpose.
- [BLOCKING] F-1 variables n_eq / n_skew (lines 457-458, 1072), DIAG_*_GRACE_FRAMES, DIAG_POST_RESTORE_SETTLE_FRAMES, AC-DO-90, F-6 throttle: [main review + qa-lead + systems-designer + performance-analyst + godot-specialist, CD confirmed at lines 457-458] The grace counters count 'consecutive rendered frames', but the classifier samples at 10 Hz. At 144 fps the 24-frame skew grace is shorter than one 12-tick Sanity run, so false DEFECT_SILENT_LIE results appear. The qa-lead points out that pausing for 3 s passes the 120-frame grace while lie_age is frozen, which contradicts AC-DO-90. The performance-analyst adds that the throttle ladder changes the cadence at runtime, so the Overlay's own load changes its verdicts. This breaks the determinism promised in the Formulas intro.
- [BLOCKING] F-1 row 8 / p_int (lines 448, 472) vs registry desync_classifier: [systems-designer, CD confirmed at line 472] Row 8 tests the float p.displayed_value == tv. Row 7 excludes disc == 0. A closed return whose displayed_value is fractional (2400.4 against tv 2400) therefore fails both rows and falls to DEFECT_UNCAUSED, even though the inline comment and the registry say a closed return is HONEST. The qa-lead adds that the fixtures use values PF-8's integer displayed_pm cannot produce (4162.5, 4787 on a 10 bp grid). The formula's totality claim currently holds only because these cases fall through to DEFECT.
- [BLOCKING] F-1 row 7 / t_return_max (static-target bound) / worked example 2: [qa-lead, CD agrees] t_return_max assumes the target is static. The GDD's own worked example 2 has tv receding faster than the follower closes. Once t_ret exceeds t_return_max, row 7 fails and row 9 raises DEFECT_UNCAUSED against a correct Filter. This happens on any degrading node while a lie ends, which is ordinary play. A tool that cries DEFECT on honest play gets ignored.
- [BLOCKING] F-1 ledger_active / subject_of(ref) (line 454) / AC-DO-134 / PF-9: [qa-lead, CD confirmed: subject_of appears only at line 454 and is never defined] ledger_active depends on a join that has no definition. If the subject is the compartment, a lie on T makes ledger_active true for the honest P and p_o2 refs, and n_skew fires a false DEFECT through branch (b). The same failure occurs for multi-surface nodes when the lie is partial. Every row of the classifier depends on this join.
- [BLOCKING] DO-14 / E-DO-37 / channel status ERROR (line 359) / AC-DO-09, AC-DO-68: [godot-specialist, CD confirmed at lines 359, 731, 1103, 1202] Panel fault isolation is specified as catching a 'throw' and naming 'the error class'. GDScript has no exceptions. A script error aborts the function and, under -d, stops the debugger. As written the rule cannot be implemented and AC-DO-09 and AC-DO-68 cannot be run. The kernel's kern:867 precedent has the same flaw and needs cross-document escalation.
- [BLOCKING] Player Fantasy anchor 2 / DO-6, DO-7, DO-31 / line 341 / AC-DO-74, AC-DO-147 / OQ-DO-18: [game-designer, CD agrees and confirmed: mark is ignored in HIDDEN at line 341 and AC-DO-147] The Overview says the MVP kill/continue playtest (X-BS-11) cannot run without the Overlay, but the Overlay gives the observer no usable path in that playtest. HIDDEN draws nothing and rejects mark. The strip shows phase and stage to the tester. The second-window view is spike-only. X-BS-11 needs a mid-sortie Attention TELL and F-9 needs a mark at boarding. Neither can be captured without contaminating the tester, so the system cannot do the Pillar 2/3 measurement it exists to support.
- [RECOMMENDED] Dependencies / Interactions B / AC-DO-71, 94, 99, 115: [main review] Neighbour claims went stale after the 2026-10-27 amendments to Suit, Controller, Graph and kernel. The GDD contradicts itself: DO-33 says APPLIED while Dependencies says provisional.
- [RECOMMENDED] States and Transitions / DO-6, DO-7: [main review + game-designer] The only route from STRIP to FULL passes through OFF, which clears the evidence. A stray F3, the key a tester can brush, also destroys history.
- [RECOMMENDED] DO-26 / mode machine (world debug draws): [game-designer] World debug-draw toggles on the layer-0 dev node, including Horror true positions, are not gated by mode and can persist into HIDDEN or STRIP. That puts the oracle on the tester's screen.
- [RECOMMENDED] DO-6 / OVERLAY_LAUNCH_OPTION: [main review + godot-specialist] Tester safety depends on passing a command-line option that store or double-click launches cannot pass. The GDD also leaves the debug-versus-release template choice for playtest builds undecided.
- [RECOMMENDED] DO-2 / AC-DO-11, 12 (export hazards): [main review + godot-specialist] Three export hazards: the custom tag reads false in editor runs; a preload or class_name in the filtered dev root breaks the release build, including through a stale class cache; F5 to F8 collide with editor shortcuts.
- [RECOMMENDED] DO-8 input bindings: [godot-specialist] With non-exact InputMap matching, Shift+F4 also fires F4, and Ctrl+Shift+F3 also fires toggle, which can clear the history the chord was meant to reveal. Echo events also auto-repeat.
- [RECOMMENDED] DO-5 / DO-28 (process model): [godot-specialist] No process_mode is stated. If SceneTree.paused is used, the Overlay stops refreshing exactly when the observer wants to inspect.
- [RECOMMENDED] DO-20 / E-DO-25 ordering: [main review, rescoped by godot-specialist] Godot runs physics steps before _process, so the real exposure is the open tick-source ADR (kern D.4 vs D.5) and an unpublished Filter memo key.
- [RECOMMENDED] F-1 closing() step test: [systems-designer] The step test uses tol(kind) as slack, which allows about 20 times the legitimate per-refresh motion. A needle diverging at tens of deg/s still reads RETURNING.
- [RECOMMENDED] DO-21 row 3 (DEFECT_NO_LEAK) / Player Fantasy line 50: [game-designer, CD confirmed: PF-G8 and pf:309 force GLEAM] Row 3 tests a bit the Filter guarantees, so it can never fire. Real leak failures go undetected: a dropped or sub-minimum gleam, or an FX-cap cut.
- [RECOMMENDED] DO-21 / DO-18 / DO-31 (evidence retention): [game-designer] DEFECT classes are instantaneous and nothing latches them. A transient defect is lost, and OFF or a restore clears what history exists. DEFECT_UNCAUSED covers 7 different failures and carries no reason.
- [RECOMMENDED] F-1 row 5 / LEAK_EPS_DEG / angle(v): [main review + systems-designer] drawn_value is ambiguous before or after pixel snapping, which causes false BYPASS. The row compares floats at an inclusive boundary, and there is no calibration guard for hi <= lo.
- [RECOMMENDED] F-7 / F-6 / HIDDEN cost / F-8: [performance-analyst + game-designer + systems-designer] The mean-only gate misses 2 ms refresh spikes. HIDDEN pulls every channel during the playtest the Overlay is meant to keep clean. The throttle ladder is ill-formed when R is 2 or 3. F-8 hides a probable one-frame hash spike, and its range is unmeasured.
- [RECOMMENDED] F-2 / F-3 hook window: [systems-designer + performance-analyst] Partial runs are not handled. A Release budget is applied to dev-template timing, which gives a permanent WARN. One outlier sticks max for 60 s.
- [RECOMMENDED] AC-DO-80 / AC-DO-82 / AC-DO-109 / plate alpha: [main review + qa-lead] Contrast is checked against the opaque plate colour, not the composite over the world. The Filter on/off pixel-diff of 0 cannot pass, because the numerals and the world bleed-through legitimately differ.
- [RECOMMENDED] Acceptance Criteria (seams and coverage): [qa-lead] T-1 to T-6 are only requests. There is no end-to-end honest soak and no seeded-defect run, which would have caught both original blockers. AC-DO-07 depends on an unpublished memo-hit counter.
- [RECOMMENDED] Acceptance Criteria (untestable list): [main review + qa-lead + game-designer] About 13 ACs are subjective, non-gating or bundled (Feel bullets, 80, 85, 95/96, 104, 107, 116, 74, review checklists).
- [RECOMMENDED] Dependencies B / OQ-DO-24: [main review] The open Boarding channel question changes the channel count of 15 in six places.
- [RECOMMENDED] Overview / systems index (effort S): [main review, agreed by game-designer] The real effort is L, and the cost is spread across sibling epics.
- [RECOMMENDED] Player Fantasy line 50: [game-designer] The Fantasy claims to prove that each consequence agreed with the ship, but there is no physical-consequence probe (frost, hiss).

## Review — 2026-10-27 — Verdict: NEEDS REVISION
Scope signal: L
Specialists: none (lean re-review)

Summary: Verdict: NEEDS REVISION. The fixes are targeted edits; nothing here needs a rethink of the design.  **What the revision fixed.** It properly resolved all 7 prior blockers: - lie_intent and the DELIBERATE tags - ticks and folds in place of frames - integer p_int - the stall clock - lie_targets - the DIAG_ERR results - the observer log  The design itself is sound. Its fantasy is that every 'the gauge lied' report classifies as DELIBERATE or a named DEFECT within one reproduction. The design serves that, and the main review's recomputed arithmetic holds up.  **Where I differ from the main review.** It held that nothing reached BLOCKING. My spot-check of F-1 lines 461-491 and E-DO-19 at line 757
Prior verdict resolved: Partly
Findings:
- [BLOCKING] Formulas F-1 (line 468) vs E-DO-19 (line 757) / AC-DO-130: [main review, escalated by creative-director] I confirmed this in the text. F-1 line 468 sets tol_eff = max(tol(kind), q_display) for every ref, and line 467 sets q_display >= 1. Line 478 sets d_int_u to 1 for binary-frame refs. So silent_ok (line 479, d_int_u > tol_eff) is never true on STATE_GLYPH, HOUSING_GLOW, MACHINE_FRAME and SPRITE_SWAP refs, and DEFECT_SILENT_LIE cannot fire on them. E-DO-19 (line 757) says the opposite: 'tol is 0 and q_display is not applied'. The formula is the normative text an implementer codes and tests against, so a faithful build silently loses silent-lie detection on the diegetic housing and glyph surfaces. Those surfaces carry the game's 'the instrument lied' horror. This is a false negative in the system's core job, and it is why I raise it from RECOMMENDED to BLOCKING.
- [BLOCKING] AC-DO-45, AC-DO-34, AC-DO-37 (cadence): [main review, escalated by creative-director] These three criteria still use the retired per-refresh and per-frame cadence: 'at most 6 frames later at 10 Hz', a 'SKEW window of 24 frames', 'per refresh' sampling and the tol_eff slack name. DO-21(5), E-DO-15 and F-1 (lines 474-489) now run classification at folds (12 ticks), measure skew in ticks, and use q_display as the step slack. A rule-correct implementation fails AC-DO-45 at 60 fps. An acceptance criterion that a correct build fails cannot gate a story.
- [BLOCKING] P-SANITY / AC-DO-59 vs Sanity ledger schema (sn:170): [main review, escalated by creative-director] Sanity's ledger now has thirteen lies[] fields, including 'direction', which Sanity's own review added on 2026-10-27. AC-DO-59 asserts 'all twelve fields', so it fails against the dependency as it stands. 'direction' (COMFORT and so on) is also the field an operator most needs to judge whether a DELIBERATE row is fair.
- [RECOMMENDED] F-1 p_int / lie_intent for TICK, STALE, BREATH and SOUND-only lies: [main review] For numeral-only readouts the perceived field is ambiguous: p_int uses displayed_pm, while PF-8 says TICK and STALE act on displayed_value. d_intended_pm is undefined for these lie kinds. Most MVP live refs are numerals.
- [RECOMMENDED] DO-35 observer log flush / DO-11 / E-DO-02 FAULTED in the playtest preset: [main review] The log is written only at folds, and no fold runs while T is frozen. A MARK during a pause, a FAULTED line, or a MARK in OFF mode can therefore be lost. FAULTED behaviour is also unspecified for the playtest preset.
- [RECOMMENDED] DO-21 row 9 'why' totality: [main review] A reachable path has no 'why': a new ledger lie goes ACTIVE while the previous lie is still in RETURN.
- [RECOMMENDED] F-1 n_eq firing tick; AC-DO-28/29/30/90/156: [main review] Sites disagree on when n_eq fires: 26.0 s vs about 26.2 s. Several injected tick values (121, 25, 131, 119) are unreachable because counters advance in steps of 12, and not all are labelled as probes.
- [RECOMMENDED] F-9 T_enter: [main review] T_enter is read at a refresh tick that can be throttled, so the stopwatch depends on the Overlay's own load and can disagree with the fold-written log.
- [RECOMMENDED] F-1 T_stall when q_display is unpublished; E-DO-10: [main review] With q_display unpublished, the stall clock can never re-anchor, which brings back the old false DEFECT_UNCAUSED on long honest returns.
- [RECOMMENDED] Player Fantasy failure condition (line 82), guard rail 1 (line 119) vs the playtest preset (OQ-DO-25): [main review; creative-director concurs on pillar grounds] The fantasy says it fails if 'any build a player can obtain contains the Overlay'. The playtest preset hands outside testers exactly such a build, with a reveal chord. This is a vision statement contradicting the design. I am not blocking on it only because the user's ruling on OQ-DO-25 is pending.
- [RECOMMENDED] AC-DO-74 tester-capture scan: [main review] Sampling every 5 s cannot prove a tester never saw the strip.
- [RECOMMENDED] AC-DO-155 / FX-SOAK: [main review] There is no reduced-motion soak pass (rm 0.6, t_return_max 38.4 s), which is where earlier false defects appeared.
- [RECOMMENDED] MVP scope vs OQ-DO-26 pre-epic dependencies: [main review] The Filter publishes no lie_intent yet, Sanity params have no schema, and the Instruments probes are not live. Until those land, the MVP classifier raises none of DEFECT_SILENT_LIE, DEFECT_BYPASS or probe-based DEFECT_NO_LEAK, yet the scope statement lists the classifier as delivered.
- [RECOMMENDED] AC-DO-20 / AC-DO-17 lints: [main review] A scanner cannot know a literal's role, so the literal-denylist lint is unworkable. The 'san' substring scan over-matches words like sand and sanitize.
- [RECOMMENDED] Registry (design/registry/entities.yaml): [main review] desync_classifier still uses frame-based graces and the old disc definition. diag_panel_contract says 15 channels (the GDD says 14). The Filter's 53.3 s figure should be 38.4 s.
