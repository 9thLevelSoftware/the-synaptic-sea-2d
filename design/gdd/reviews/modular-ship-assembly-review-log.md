- [BLOCKING] MSA-4 L157 / FB-7 INV-10 L326 / E-33 L974 / AC-MSA-59, 118: [qa-lead, confirmed by CD spot-check] The GDD contradicts itself on how long pending lives. MSA-4 says pending lives across 'exactly one tick boundary'. INV-10 requires the pending target to be FREE (weld) or WELDED (cut). But E-33 keeps pending set until submit_T + 13 after a P2 rejection, and AC-MSA-59 makes the losing seat's target WELDED while its pending is still set. Two consequences follow. The debug invariant fires inside a test the GDD itself requires. An autosave taken in that window fails to restore under AC-MSA-118, so a legitimate save becomes unloadable.
- [BLOCKING] AC-MSA-61 / Spike S7 / MSA-4 persist true / AC-MSA-05: [qa-lead] AC-MSA-61 is the main save/restore equivalence test, and it cannot pass as written. assembly.state is persisted and covered by the hash, but every restore clears last_result. So after the first DONE, a restored run's hash differs from the uninterrupted run at almost every tick, and last_result is not on the permitted-difference list. This is the BLOCKING evidence for every Integration story in the weld, cut and install group. It also decides the MSA-4 persist true/false fork, which the main review left as a free choice.
- [BLOCKING] E-35 L976 / Spike S6 L1798 / AC-MSA-51 (inherited from the kernel, command-simulation-layer.md CR-9): [godot-specialist, confirmed at L976 and L1798] The fault model assumes an apply can throw and that the batch loop catches it. GDScript has no throw/try/catch. A runtime error ends the function with a default return, and the caller carries on. As written, S6 and AC-MSA-51 ('a stub mutator that throws') cannot be implemented. A half-applied A3 (Layout done, Body not) would also go undetected, since the release verifier checks only INV-1, INV-2 and INV-7. This is an engine fact the 'atomic apply, defect becomes FAULTED' premise rests on.

Perception Filter, HUD, Instruments, Overlay, Sanity and Horror all exist with Status: Designed. As a result, ACs 13, 14, 21, 31-33, 83 and 84 look blocked when they are not.
