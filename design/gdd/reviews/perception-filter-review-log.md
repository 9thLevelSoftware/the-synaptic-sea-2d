- [BLOCKING] Formulas D.5 RETURN / States S3 / PF-8 / AC-PF-19 vs AC-PF-87 / E-PF-2: [systems-designer; CD verified lines 731, 1772, 1773] AC-PF-19 requires amp to be 0 at and below LEAK_EPS_DEG after removal. [main review] Separately, the RETURN amplitude is unbounded when the truth moves away during the return (it can reach 1409 pm), and it is discontinuous at the branch boundary disc_end = 2 x eps.
- [RECOMMENDED] Player Fantasy (V1, V4, 'room answers') vs PF-15 / PF-16 / D.5: [game-designer; CD priority] The gleam is mandatory, always on and has a floor of 400. On binary surfaces (FALSE_OK, FALSE_FAIL, housing, glyph, SPRITE_SWAP), once players learn what violet means, it tells them both where the lie is and what the truth is: invert the reading. D_draw ignores how far the zone is, the departure is capped at 0.4 of the arc, and D.3's own example stops at 800 when the zone centre is 900. Leak-only lies (displayed value close to the truth, but still violet and sound) teach players that 'violet does not mean wrong' and still use up LIES_MAX slots.
