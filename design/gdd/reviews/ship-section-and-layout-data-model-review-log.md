Findings:
- [BLOCKING] Detailed Rules LY-7 / LY-12 a / LY-15 table + prose; Formulas D.9; AC-32/33/38/63: [main review + systems-designer + qa-lead + godot-specialist; confirmed by creative-director spot-check of L228, L242-251] The stable-key invariant ('an attach renumbers nothing', L228) is not reconciled with the per-state rect sets in LY-15. FREE builds a plate, WELDED builds 'two jambs per hatch' plus a leaf, CAPPED builds a cap plate, and CUT_OPEN builds a plate. D.9 assigns idx only to static rects and leaves. The variant pieces have no reserved idx. The geometry is also degenerate at MVP. The table gives the FREE plate as `width_tiles × 48` (the full socket), but the prose (L244) says it covers 'the doorway'. The MVP socket is 2 tiles (96 px) and the hatch is 96 px, so both WELDED jambs are 0 px wide. The HULL wall run is never stated to split around the socket span, so the plate collides with the wall rect (RECT_OVERLAP). The LOW-hinge pocket of D.18 lies outside the run. [systems-designer] The active set also depends on the mate: a one-sided hatch keeps its plate. AC-63 and AC-38 cannot both be implemented without an invented idx scheme.
- [BLOCKING] Detailed Rules LY-11 (L225), LY-28 row leaf_would_overlap (L309), Edge Cases L978, AC-55..58: [systems-designer; confirmed by creative-director at L225/L244] `leaf_would_overlap` takes `door_ref = (section_id, door_index)`, which names one section's leaf. A mated hatch is two leaf rects driven by one `area` (LY-15). A 16-px foot box straddling the seam (x 688..703 in the AC-58 fixture) overlaps only B's leaf. A close validated against A's door_ref therefore passes while B's leaf grows over the body. This breaks the PCI:650 invariant on the MVP's only hatch and turns Body's PC_FOOTPRINT_OVERLAP into a live defect. AC-55..57 test only an interior door.
- [BLOCKING] Detailed Rules LY-12 d (L232), LY-16, LY-17 (L255); LM2/LM3 dirty keys; D.12 (L699); AC-40, AC-73, AC-79: [systems-designer; confirmed by creative-director at L232/L255/L699/L1369] `version` bumps and dirty keys cover only MOVED sections. The UNMOVED mate section's socket state and rect set change too: on a weld its plate becomes jambs plus a leaf, and on a cut its leaf becomes a plate. If a hatch is open when it is cut, the kept section's light gap becomes a solid plate with no version bump. The Emitter's version-keyed static layer then keeps passing light through a solid plate. That is the see-through-but-solid failure the secondary design test forbids (Pillar 1). AC-79 and D.12's dirty-key count (4) encode the defect.
- [RECOMMENDED] LY-10, LY-26 c, OQ-3/4, AC-19/20/51/52/54/62/66: [main review + qa-lead + game-designer] The Graph `opening(edge_id)`, the M1 id-base return, `weld_join` returns and `seam_view` now exist, but this GDD still treats them as unanswered ASKs. [qa-lead] AC-66 asserts the stale text must remain, so a refresh would fail it by construction. [systems-designer] The stale_leaf restore path must survive the refresh. [game-designer] OQ-14(c), the door travel owner, is still genuinely open.
- [RECOMMENDED] Player Fantasy step 3, Game Feel, LY-11, Edge Case L914, OQ-14(c): [game-designer] Two incompatible doors are described. The fantasy and feel text promise a sliding leaf that grows each tick. IA-24 and the registry `door_attempt` specify a 30-tick attempt and then a binary jump to area_max. A later tween added to make the door 'slide' would break the rule that the sprite equals the rect. The edge case at L914 is wrong under a binary jump.
- [RECOMMENDED] D.14 South band; SOUTH_BAND_SEVERITY; face_h_px: [game-designer + systems-designer] D.14's 72-px face on a south run contradicts Pipeline PR-5, which requires a cap-only south wall. The real case is an interior E-W partition, whose face hides the walkable floor of the north room by draw order. That is a Pillar 1 and Pillar 2 tell problem, and it is arithmetic, not a spike unknown. The band is also not clipped to shallow rooms.
- [RECOMMENDED] Visual/Audio row 'wall in the way'; AC-124/126: [game-designer] 'Drawn extent equals the rect' is false for walls (a 24-px footprint against 96 drawn rows). A correct art build would fail the evidence ACs.
- [RECOMMENDED] LY-12 e / LY-28 / D.9 result contract: [main review + godot-specialist + systems-designer] The query record layout is undefined. Buffer reuse aliases between consumers. Key columns need 64-bit storage (the main review's PackedInt32Array suggestion overflows for section_id >= 2^19). A returned reused buffer cannot be both allocation-free and safe under copy-on-write. The aabb convention is closed in D.9 and half-open in D.2 and D.22.
- [RECOMMENDED] Edge Cases 'Capacity, ids' vs D.9; MAX_RECTS_PER_SECTION: [main review + systems-designer] The section-id cap is 2^31-1 in Edge Cases but 2^20 in D.9. Static plus leaf (plus variant) idx can exceed RECT_KEY_STRIDE and collide with the next section's keys.
- [RECOMMENDED] MAX_BODIES; LY-27/LY-29; AC-85/86: [main review + qa-lead] The effective body ceiling is 4 (Lighting) against a knob of 8. The MVP margin is zero. A cut at the ceiling contradicts 'infallible apply', and AC-85/86 freeze that defect into the closed reason set.
- [RECOMMENDED] LY-16/LY-17/D.12 host-body rule: [main review] The survivor is 'socket_a's body' by an unconfirmed Assembly convention. Reversed arguments would dissolve the home-ship's body. The new body's origin_section_id is unstated.
- [RECOMMENDED] LY-14 GEOM_OVERLAP / D.6 / hatch alignment: [systems-designer] GEOM_OVERLAP runs over rects_in (occluders only, current leaf state). Low props escape the test, the verdict flips as a door animates, and floor-on-floor overlap is unchecked. Hatch offsets inside a span are not compared, which produces misaligned mated doorways on sockets of 3 tiles or wider.
- [RECOMMENDED] LY-26 e / D.10 drift classifier: [systems-designer] Socket position and wall rect edits classify as 'visual-only', so a welded save restores with broken abutment.
- [RECOMMENDED] LY-12 d version semantics: [godot-specialist] Every leaf change bumps the static version. A stepped slide would force a full consumer rebuild every tick.
- [RECOMMENDED] LY-31 PROJECTOR / Y-sort; AC-140: [main review + godot-specialist] The reparent-per-weld scene shape is [UNV] and conflicts with a single Y-sort scope.
- [RECOMMENDED] LY-26 a snapshot/JSON; D.10 hash cadence: [godot-specialist] JSON turns int keys into strings and numbers into floats, and the u64 hash representation is undefined. Snapshots may alias live packed arrays. The hash cadence is unstated, and a GDScript byte loop is slow.
- [RECOMMENDED] AC group K, D.22, OQ-2: [main review + systems-designer + godot-specialist + qa-lead] The performance ACs bind to no machine. D.22 omits cell lookup, de-dup/merge, call overhead and Emitter-sized queries.
- [RECOMMENDED] Dependencies table / status text: [main review] Existing GDDs are labelled 'in flight' or 'undesigned-provisional'. Adaptive Audio, In-World Instruments and HUD & Suit Layer are missing from the Dependencies table, so bidirectionality is not shown.
- [RECOMMENDED] Player Fantasy permanence; X-3/X-4; LY-13 socket economy: [game-designer + main review] The claim 'carries that scar for the rest of the ship's life' is undone by restart-from-autosave, which is most likely right after a crisis cut. X-3 (choice of what to weld) is unfalsifiable with one socket and one mate. Whether the cut is MVP scope is unconfirmed.
- [RECOMMENDED] LY-14 one-sided hatch; UI Requirements: [game-designer] Welding onto a hatchless mate spends the irreversible socket with no player-readable 'no passage' cue.
- [RECOMMENDED] LY-11 / Game Feel failure texture: [game-designer] A blocked close and an unpowered door are indistinguishable (both show only a motor whine), which breaks the 'why is always geometric' promise.
- [RECOMMENDED] Acceptance Criteria testability (AC-14, 115, 130, 133, 135, Feel X-1..X-5, 141, 124 filenames, stub table): [main review + qa-lead] Several ACs have no fail condition, sample size or coding rule. - [RECOMMENDED] D.13 vs AC-140 / AC-100 / registry roster; LY-13 four-facing table; D.3 run overlap; D.19 escape budget; lint table: [main review + systems-designer + qa-lead] Tile totals disagree (502 vs registry 453).
