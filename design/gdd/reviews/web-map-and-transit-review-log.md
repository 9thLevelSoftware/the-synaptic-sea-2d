The economy-designer verified that the unrepaired drip ends in SCRAM, not FUEL_LOW. AC-WM-37 gate (1) passes tautologically and gate (3) can never fail.

Findings:
- [BLOCKING] WM-10 step 1, WM-24 guard (3); AC-WM-45/47/94: [main-review, confirmed by creative-director spot-check of L223-226 and L273] As written, the avatar-present dormancy guard refuses every return hop. WM-24 runs guard (3) in validate: it refuses a flip that 'would set dormant a section whose body hosts the avatar (Body body_of_actor)'. WM-10 puts the origin derelict's M19 flip in the Graph phase (step 1), and BM5 moves the avatar into the pod later, in the Body phase (step 3). At validate time body_of_actor is still the derelict, so every pod_hop from a derelict is rejected WEB_DORMANCY_AVATAR. The player can never come home, which is a P5 'loss is not total' failure and a soft lock. AC-WM-47 and AC-WM-45/94 contradict each other.
- [BLOCKING] AC-WM-15 (L1492); States and Transitions note (L371); D.2 example; WM-13; E-23: [main-review, confirmed by creative-director arithmetic against WM-14 L237] Take a snapshot after 10899. pod_arrive applies late at 10901, but arrive_T is nominal (10900). L371 and AC-WM-15 say the settle applies at 10946 and that the avatar exits one tick late. A correct implementation would turn this BLOCKING Logic AC red, which is the same defect class as the prior blocker.
- [BLOCKING] OQ-WM-39; WM-9 NOT_LIT clause (L221); AC-WM-128, AC-WM-81e; Player Fantasy Design Test summary (L153); E-03/E-16: [main-review; creative-director concurs] The lit-gate decision is still escalated and unruled.
